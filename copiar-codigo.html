📋 Código del Apps Script

Cargando el código…

  1. Toca el botón rojo.
  2. Abre el Apps Script y entra a INGRESOS.
  3. Borra todo lo que hay (seleccionar todo → borrar).
  4. Pega (mantén apretado → Pegar).
  5. Guarda 💾 y espera que no diga «Cambios sin guardar».
  6. Implementar → Administrar implementaciones → lápiz → Versión nueva → Implementar.

Si el botón no copia, mantén apretado dentro del cuadro de abajo → Seleccionar todo → Copiar.
